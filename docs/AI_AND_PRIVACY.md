# AI, Privacy, and Learner Control

Readbeat uses AI to create and adapt Mandarin practice material. The learner remains in control of what is created, played, repeated, recorded, or explored.

## AI-assisted experiences

- Generate stories around learner-selected themes and levels.
- Adapt vocabulary, sentence complexity, and supporting explanations.
- Support narration and recording-based practice.
- Develop bounded branches for choose-your-own-adventure stories.
- Organize song-based material for listening and sing-along practice.

## Guardrails

- Generated language remains reviewable and correctable.
- User recordings are distinct from generated audio.
- Private recordings and learning activity are not published in this repository.
- AI-powered actions on the public website should direct visitors to the latest app.
- The product should not make high-stakes judgments about a learner’s ability or identity.

## Public repository boundary

This repository contains product documentation and approved public media only. It does not contain the private application source, credentials, private user recordings, personal learning histories, or proprietary generation workflows.
