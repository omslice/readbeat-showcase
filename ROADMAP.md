# Public Roadmap

## Now

- Improve public access and remove unnecessary sign-in friction.
- Refine the “Read. Listen. Sing along.” experience.
- Add recording upload beside story creation.
- Remove unnecessary “new words” sections from song cards.
- Ensure public-site AI actions direct visitors to the latest app.
- Improve release and updater reliability.

## Next

- Develop choose-your-own-adventure story creation.
- Improve level-aware Mandarin generation and scaffolding.
- Strengthen listening, repetition, and recording workflows.
- Add clearer content provenance and correction tools.
- Publish privacy-reviewed screenshots and demonstrations.

## Later

- Expand interactive story formats.
- Add richer learner-directed practice paths.
- Improve cross-device continuity while preserving privacy.

Priorities may change with testing and learner feedback. This repository deliberately omits proprietary implementation details.
