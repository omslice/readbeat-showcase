# Readbeat

**Read. Listen. Sing along.**

Readbeat is an actively developed Mandarin learning experience that turns language practice into interactive stories, recordings, songs, and adventures. It is designed for learners who want understandable, repeatable content rather than disconnected drills.

> **Status:** Actively under development. This repository is a public product showcase and development log; the application source and private user content remain private.

## Why Readbeat exists

Language learning sticks when reading, listening, speaking, music, and curiosity reinforce one another. Readbeat brings those modes together so learners can follow content they enjoy, hear natural pronunciation, revisit difficult lines, and gradually make the language their own.

## Learning experience

- Read Mandarin stories with learner-friendly support.
- Listen to narration while following the text.
- Practice songs and lyric-based material.
- Upload a recording for personal learning workflows.
- Create new stories around selected themes and levels.
- Explore a developing choose-your-own-adventure format.
- Use the public website for browsing while reserving AI-powered creation for the latest app.

## How AI is used

| AI-assisted capability | Contribution | Learner control |
|---|---|---|
| Story creation | Produces level-aware Mandarin stories around chosen themes | Learners choose the topic and can regenerate or revise |
| Adaptive language | Adjusts vocabulary, sentence complexity, and scaffolding | Learners control the intended level |
| Learning support | Helps create explanations, translations, and practice material | Support remains optional and tied to the content |
| Audio workflows | Supports narration and recording-based practice | Learners choose what to play, repeat, or upload |
| Interactive adventures | Generates bounded story branches from learner choices | Learners direct the path through explicit choices |
| Song-based learning | Helps organize Mandarin content for listening and sing-along practice | Learners select and revisit the material |

AI is used to create practice material—not to grade a learner’s identity, ability, or worth. Generated language should remain reviewable, correctable, and clearly distinguished from user recordings.

## Product principles

- **Enjoyment matters:** compelling stories and music create reasons to return.
- **Comprehensible input:** content should stretch the learner without becoming noise.
- **Multiple modes:** reading, listening, speaking, and singing reinforce one another.
- **Learner agency:** users choose themes, levels, repetition, and story direction.
- **Privacy:** private recordings and personal learning data are not published here.
- **Clear boundaries:** public-site actions requiring AI should direct users to the latest app.
